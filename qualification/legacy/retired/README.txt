These original Alpine archives support only the v0.22.29 installed-component
upgrade qualification. Current production catalogs use the publisher's newer
openjpeg and zlib revisions. No production installation reads these fixtures.

The previous publisher URLs were retired. The files were recovered from existing
verified caches, retain their original publisher signatures, and match the exact
published v0.22.29 catalog SHA-256 hashes and sizes. SHA256SUMS and provenance.json
bind each fixture to its architecture, source URL, package license and source.
Source catalog: https://github.com/floegence/floe-native-apps/blob/v0.22.29/catalog.json

OpenJPEG uses BSD-2-Clause; zlib uses the Zlib license. The original license texts
are included as openjpeg.LICENSE and zlib.LICENSE. These are unmodified archives,
not a reconstructed or relabeled installed stack.
